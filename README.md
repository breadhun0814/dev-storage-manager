# 개발 저장공간 관리자 (dev-storage-manager)

Windows용 로컬 개발 저장공간 관리자 0.15.0 시험 버전. 실제 폴더 용량과 큰 파일 상위 500개를 분석하고, 선택 폴더의 파일/하위 폴더 목록을 읽기 전용으로 탐색합니다. 검색·정렬·CSV/JSON 저장을 제공하며 공유 보호와 유형별 시험/내용 검증을 통과한 Python/pytest 캐시만 직접 확인 후 휴지통으로 이동합니다. 시작 시 정리는 비활성입니다. 정리 이력은 백그라운드에서 200개씩 조회하고 전체 경로/실패 이유 검색과 페이지 이동을 지원합니다. 보조 작업은 '관리 · 도구' 메뉴에 있습니다.

## 처음 사용하는 분께

**[사용 방법: 실행부터 분석·정리·복원까지](docs/USER_GUIDE.md)**에서 실제 화면의 버튼 이름과 순서를 안내합니다. 후보 표가 비어 있거나 휴지통 버튼이 비활성인 경우도 설명합니다. 처음에는 **관리 · 도구 → 시험 프로젝트 만들고 분석**으로 개인 파일 없이 익힐 수 있습니다.

현재는 **0.15.0 시험 버전**입니다. GitHub의 **Code → Download ZIP**은 소스 코드이며 실행 파일 ZIP이 아닙니다. 소스로 실행하는 방법은 아래에 있습니다. 별도로 받은 Windows 실행 파일 ZIP은 전체 압축을 푼 후 `DevStorageManager.exe`를 파일 탐색기에서 실행합니다.

## 설치·실행

Windows x64 Python 3.12가 필요합니다. 저장소 루트의 PowerShell에서:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\pythonw.exe scripts\run.pyw
```

`scripts\run.pyw`는 소스 경로를 직접 연결하므로 편집 설치가 필요 없습니다. 실행 중 명령창은 생기지 않습니다. 진단할 때는 pythonw 대신 python을 사용하세요. `py`가 없다면 설치한 Python 3.12의 절대 경로를 사용하세요. 이 환경에서는 긴 경로로 편집 설치 빌드가 실패하여 위 소스 실행 방식을 사용합니다.

폴더 추가 → 목록 선택 → 선택 프로젝트 분석. 완료 후 폴더별 표와 오류·제외 범위 탭을 확인하세요. 분석 취소 시 확인된 부분 결과를 저장합니다. 목록을 선택하면 마지막 결과를 엽니다. 검색은 표시만 필터링하며 분석 제외 설정이 아닙니다. 목록에서 제거는 DB 기록만 제거합니다.

분석 제외 목록 버튼에서 프로젝트 기준 상대 경로를 한 줄에 하나씩 입력할 수 있습니다. 다음 분석부터 적용되며 절대 경로와 상위 이동은 허용하지 않습니다. 결과에 적용된 제외 목록을 보존합니다.

프로젝트·정리 후보 탭에서 후보를 선택하면 근거·주의·재생성 안내가 나옵니다. 포함 파일·변경 여부 검토는 별도 작업 스레드에서 대상 메타데이터를 재탐색하고 파일 경로 목록을 표시합니다. 판별은 설정 파일과 파일명 관계에 근거한 후보이며 설정의 유효성까지 보장하지 않습니다.

'정리 환경 시험'은 앱 데이터에 직접 만든 작은 시험 프로젝트로 링크/보호 경로와 유형별 실제 휴지통 동작을 확인합니다. 공유 보호와 해당 유형의 시험을 통과한 실행 세션에서 Python 3.12 캐시 또는 지원한 기본 pytest 캐시 한 후보를 개별 검증·사용자 확인 후 이동할 수 있습니다. 초기 정리는 항상 비활성이며 이전 점검 기록으로 자동 활성화하지 않습니다. 시험 캐시가 휴지통에 남을 수 있습니다. 정상 Windows 0.6.1 Python 시험 캐시의 이동 성공은 사용자 보고이며, 에이전트 실행 환경의 휴지통 차단과 최신 유형의 미검증 상태는 docs/SUPPORT.md와 docs/USER_VALIDATION.md에 구분합니다.

이전 완료 결과와 비교 버튼은 같은 제외/오류 범위의 완료 결과만 비교합니다. 보고서 내보내기는 JSON 또는 폴더 요약 CSV를 새 파일로 저장하며 기존 파일은 덮어쓰지 않습니다. JSON에는 원래 프로젝트 경로가 포함되므로 공유 전 내용을 확인하세요.

분석 DB는 `%LOCALAPPDATA%\DevStorageManager`에 저장합니다. 동시에 하나의 앱만 실행합니다. 정리 이력에서 성공/실패/미확정과 이동 확인 크기·관측 여유 공간을 구분합니다. 자동 복원이나 휴지통 비우기는 제공하지 않습니다. 실제 Windows 휴지통 긍정 경로·깨끗한 환경 시험은 남아 있습니다. Windows 10 지원은 미확인입니다.

## 검사

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

시험은 pytest 임시 디렉터리만 사용합니다. 읽기 실패는 주입 시험으로, 심볼릭 링크는 OS 권한이 없으면 skip으로 표시합니다. 실제 개인 프로젝트를 시험 대상으로 쓰지 마세요. 일반 파일도 분석 중 다른 프로그램이 바꾸면 집계가 달라질 수 있습니다. 결과는 실시간 스냅샷이 아닙니다. 긴 네트워크/파일 시스템 호출은 취소 반응을 지연시킬 수 있습니다.
