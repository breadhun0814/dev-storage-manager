## 증거 수준과 최종 배포 전 남은 일

0.15.0 전체 로컬 검사는 **182 passed, 3 skipped**였다. 새 누락/중복 시험은 수정 전 실패를 재현하고 수정 후 통과했다. 상세는 VALIDATION_0150.md이다. offscreen 자체 검사는 실제 사용자의 화면·휴지통 복원 시험을 대신하지 않는다.

사용자가 제공한 0.6.1 결과는 링크 경계/보호/시험 Python 캐시의 실제 휴지통 영수증·원래 경로 소멸/원본 보존의 네 항목 통과다. 이는 USER_VALIDATION.md의 사용자 보고이며 현재 버전의 전체 흐름을 독립 확인한 결과는 아니다.

최종 배포 전에 한 묶음의 검증으로 진행할 항목:

1. 새 Windows 11 일반 사용자 환경에서 ZIP 해제→실행→새 시험 프로젝트→분석→후보 검토→직접 확인→휴지통 이동→결과/이력→재분석.
2. Python/pytest 각각의 실제 휴지통 이동과 Windows 휴지통 수동 복원 후 경로·내용 확인. 미통과 유형은 활성화하지 않음.
3. 앱 재시작 후 환경 자격 초기화/재분석 필요 상태/중단 이력, 실제 화면의 한국어·공백·DPI 확인.
4. 실제 생성 권한이 있는 환경의 세 링크 검사와 큰 실제 임시 트리 측정. Windows 10은 별도 시험 전 지원 미확정 상태 유지.

다른 프로젝트는 수정하지 않는다. 2026-10-31 사용자가 GitHub 업로드와 사용 방법 포함을 요청하여 이전 업로드 보류는 해제되었다. 시험 버전의 소스·검사·설명을 반영하며 정식 완료로 표현하지 않는다. 작은 수정마다 사용자의 재시험을 요청하지 않고 독립 검증과 문서 정리를 먼저 진행한다.
