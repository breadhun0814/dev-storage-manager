## 새 검사

- 실제 생성한 한국어/공백 경로에서 직접 파일·폴더를 나열하고 바이트와 mtime 불변을 확인한다. 하위 폴더로 이동/상위/프로젝트 처음/새로 읽기/리터럴 검색/파일 경로 확인을 Qt 흐름으로 연결한다. 파일 행은 열기·실행·삭제를 지원하지 않는다.
- .git/앱 보호/사용자 제외는 바이트 미확인·열기 제한으로 표시한다. 등록 경계 바깥과 분석 후 새 폴더는 열지 않는다. 현재 제외 설정도 적용한다.
- 링크/reparse 및 파일별 읽기 실패는 메타데이터 대역으로 재현하고 하위 경로를 따라 읽지 않는 것을 확인한다. 이 대역 검사를 실제 링크 생성 시험의 대체로 주장하지 않는다.
- 최대 표시 상한은 limited/전체 아님이며 취소는 부분 목록이다. 닫거나 취소 버튼을 누르면 작업에 취소를 보내고 완료 결과로 창을 재개방하지 않는다.
- 소유한 임시 폴더의 실제 Windows DACL을 제한하여 폴더 탐색이 OSError를 보고하는지 검사하고 finally에서 원래 DACL을 복원했다. 개인 파일 권한은 변경하지 않는다.
- Python 소스 내용을 같은 크기로 바꾸고 수정 시각을 원래 값으로 돌려도 검토 후 정리 계획의 변경 검증이 차단하는 회귀 검사. 소스 바이트는 변경한 시험 값 그대로 보존한다.
- Qt offscreen에서 일반 크기와 800×600 부모 창에 맞춘 탐색 창을 육안 확인했다. 전체 경로는 선택 가능한 읽기 전용 칸으로 보존한다. 모든 실제 DPI/실물 모니터 시험을 의미하지 않는다.
