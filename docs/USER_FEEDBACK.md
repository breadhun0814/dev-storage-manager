# 2026-10-30 실제 사용 피드백과 다음 작업

사용자는 0.4.0 시험 버전을 사용한 뒤 다음 문제를 보고했다. 정식 완료로 간주하지 않는다.

1. 초기 창이 너무 크고 축소하면 등록 프로젝트/파일 이름이 잘린다. 작은 화면에서 중요한 이름과 작업이 보이도록 레이아웃을 재구성한다. 프로젝트 이름/경로 열의 우선순위와 폭, 화면 높이/배율 대응을 함께 확인한다.
2. 바이트 원시 숫자 대신 KB → MB → GB → TB 자동 단위를 표와 후보·포함 파일·비교·이력 전체에 일관되게 적용한다. 정렬은 원래 숫자를 사용하고 정확한 바이트는 툴팁/상세 정보로 보존한다. 단위의 계산 기준도 명시한다. 현재 일부 카드만 축약 단위이고 다른 표는 아직 원시 바이트다.
3. 후보와 포함 파일이 나열되지만 무엇을 선택하고 실행하는지 불분명하다. 폴더 탐색, 후보 선택, 포함 파일 검토, 실행 제한 이유를 구분하고 다음 행동을 안내한다. 포함 파일 개별 체크박스는 임의로 붙이지 않는다. 현재 정리 계획은 후보 폴더 단위이며, 파일별 삭제는 별도 안전 설계가 필요하다.
4. 휴지통 이동을 실행하지 못해 실제 사용 흐름을 확인할 수 없다. 환경 시험의 구체적 실패 기록과 코드 경로를 조사한다. 실패 이유와 해결 가능/미지원 상태를 UI에 알린다. 검증 장치를 우회하거나 시험 성공으로 위장하지 않는다. 영구 삭제 fallback을 만들지 않는다.
5. 사용자는 한국 시간 **2026-10-31 새벽 01:00**에 이 대화에서 개발을 계속하도록 요청했다. 일회성 자동화 ID `1`을 생성했다. GitHub 업로드 보류 지시는 유지한다.

우선순위는 축소 가능한 화면과 이름 가독성 → 일관된 용량 표시 → 후보 선택/검토 흐름 → 실제 휴지통 제한 원인과 수정이다. 수정 후 임시 자료 검사 및 화면 확인, 새 버전의 로컬 실행물과 문서를 함께 제공한다. 링크/휴지통/복원과 DPI별 시험은 실제 수행한 범위만 보고한다.
