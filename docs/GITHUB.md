# GitHub 업데이트 흐름

## 현재 사용자 지침

2026-10-30: GitHub 추가 업로드를 중지한다. 프로그램 완성 이후 실행 방법·검증 결과·제한사항 설명과 함께 한 번에 반영한다. 이미 올라간 원격 커밋은 유지한다. 그동안 소스 변경과 이력은 로컬에서만 관리하며 CI를 돌리기 위한 임시 업로드도 하지 않는다.

저장소: https://github.com/breadhun0814/dev-storage-manager (사용자가 만든 공개 저장소). Pages 주소 https://breadhun0814.github.io/dev-storage-manager/ 는 데스크톱 프로그램 실행 주소가 아니다. 사용자가 지정한 기존 공개 상태는 변경하지 않는다.

GitHub 커넥터는 기존 저장소 조회/파일/커밋 작업을 지원하지만 저장소 생성 기능은 제공하지 않는다. 사용자 생성 후 저장소를 확인했고 초기 README만 있었다. 초기 원격 커밋을 보존하면서 로컬 코드를 연결한다. 로그인 정보나 토큰은 소스/채팅/설정 파일에 기록하지 않는다.

소스, 테스트, 문서를 작은 기능 단위로 커밋한다. .venv, work, outputs, DB, 캐시 및 개인 분석 데이터는 업로드하지 않는다. 기존 원격이 있으면 내용을 확인한 후 연결하고, 강제 푸시로 기존 이력을 덮어쓰지 않는다.

원격 연결 뒤 Windows CI에서 pytest를 실행한다. 로컬에서 건너뛴 실제 링크 시험은 CI에서도 결과와 이유를 확인하며 시험하지 않은 플랫폼 지원을 표시하지 않는다.
