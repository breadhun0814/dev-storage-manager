# 0.4.0 화면 개선

0.9.0 이력: 검색은 전체 경로/실패 이유 대상, 200개 페이지와 조회 상태를 명시한다. 긴 경로/실패는 선택 가능한 읽기 전용 상세에 보존한다. 800×600에서 불필요한 프로젝트 선택/환경 자격 배너를 이력 화면에서 숨기고 진행 상태/취소는 유지한다. 활성 페이지의 최소 높이를 사용하여 아래 버튼이 선호 높이에 밀리지 않게 한다. 상태/실패 열을 남은 폭에 맞추고 실행 시각의 원본/시간대는 툴팁과 상세에 유지한다. 실제 offscreen 화면과 버튼의 창 안 배치를 확인했으며 모든 DPI 검증으로 확대하지 않는다.

참고: [Mobbin 공개 소개](https://mobbin.com/), [Uiverse 컴포넌트 분류](https://uiverse.io/).
대시보드의 정보 구분, 카드/입력/버튼 상태의 일관성을 참고했다. 외부 화면·코드·유료 에셋을 복제하지 않고 Qt Widgets와 자체 QSS로 구현한다.

- 옅은 배경, 흰 표와 카드, 파란 주요 작업, 명확한 비활성/포커스/선택 표시.
- 프로젝트 목록과 보조 도구 구분, 실제 용량/파일 수/후보/오류·제외 요약 카드.
- 진행 중에는 움직이는 상태 막대와 확인한 용량/파일 수. 완료율을 추측하지 않는다.
- 긴 폴더 접두어 대신 프로젝트 상대 경로를 표시한다. 전체 경로는 툴팁과 검색에 유지하고 정리 검토에서는 원래 정확한 경로를 표시한다.
- 실패·미분석 프로젝트로 전환하면 이전 요약 수치를 지운다. 후보를 자동으로 선택하지 않는다.
- 용량 카드의 축약 단위와 별개로 요약/툴팁에는 정확한 논리적 바이트를 유지한다.

임시 시험 자료의 실제 분석 결과를 offscreen Qt 창으로 렌더링하여 1280px 화면을 확인한다. 이것은 실제 모니터의 모든 DPI 배율 검증이나 휴지통 검증을 대체하지 않는다.
