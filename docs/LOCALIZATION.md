# 다국어 지원 · 0.16.0

## 사용 방법

**관리 · 도구 → 표시 언어 / Language**에서 선택하고 저장한 뒤 앱을 닫고 다시 실행한다. 메뉴의 언어 이름은 한국어 / English / 日本語 / 简体中文 / Tiếng Việt로 표시한다. 기본값은 한국어다. 선택은 사용자별 앱 데이터 SQLite의 `app_settings`에 저장하며 프로젝트 폴더에 설정을 만들지 않는다.

진행 중인 작업을 임의로 중단하거나 실행 중 언어를 바꾸지 않는다. 재실행할 때 언어 설정을 읽은 뒤 UI 모듈을 불러오므로 표 머리글·상태·분류도 같은 언어로 초기화된다. 언어 변경으로 정리 자격이 생기지 않으며 새 실행의 정리 자격은 계속 비활성으로 시작한다.

## 번역 범위와 영어 대체

| 언어 | 상태 |
|---|---|
| 한국어 `ko` | 기본 원문 |
| 영어 `en` | 기본 카탈로그 522개. 현재 소스에서 추출한 정적 문구 521개를 모두 포함(기존 항목 1개 포함) |
| 일본어 `ja` | 주요 화면·메뉴·상태·일부 안전 안내 185개, 나머지는 영어 |
| 중국어 간체 `zh_CN` | 같은 범위 185개, 나머지는 영어 |
| 베트남어 `vi` | 같은 범위 185개, 나머지는 영어 |

사용자가 요청한 대로 선택 언어에 없는 **앱 문구는 영어 기본 카탈로그로 대체**한다. 외부 번역/AI 서비스나 네트워크를 사용하지 않는다. 한국어를 선택했을 때는 원문을 표시한다. 전문 번역 검수 및 모든 문구의 세 추가 언어 번역은 완료하지 않았으며 완역으로 표현하지 않는다.

파일 이름·프로젝트 경로·코드·명령·기존 분석 근거와 이력은 기록 자료이므로 임의로 번역/변경하지 않는다. 과거에 저장된 한국어 오류 이유도 원문이 유지된다. Windows 기본 파일 선택기나 OS 오류 문구는 운영체제 표시 언어를 따를 수 있다. 이것들은 앱 번역 카탈로그와 구분한다.

## 카탈로그 편집

`src/dev_storage_manager/locales/{en,ja,zh_CN,vi}.json`은 한국어 원문을 키로 하고 번역을 값으로 하는 UTF-8 JSON이다. 빌드와 소스 배포에 포함한다. 언어 코드는 허용 목록만 사용하므로 임의 경로를 카탈로그 위치로 사용하지 않는다. 기존 gettext `tr()` 호출/추출 템플릿은 유지하되 실행 시 검증 가능한 JSON을 읽는다. 별도 msgfmt 설치가 필요하지 않다.

- 영어 파일에는 새 `tr('정적 원문')`을 반드시 추가한다. 카탈로그를 추출하려면 `.venv\Scripts\python.exe scripts\extract_messages.py`를 실행한다.
- `{path}`, `{count:,}`, `{p0:#x}` 등 자리표시자 이름·서식·개수를 유지한다. 순서는 바꿀 수 있다. 파일 경로나 명령 문자열을 번역하지 않는다.
- 선택 언어의 항목이 없으면 영어로 대체한다. 영어 파일이 없거나 자리표시자가 깨진 카탈로그는 시작/검사에서 오류로 처리한다. 깨진 문구로 정리 동의를 진행하지 않는다.
- `.venv\Scripts\python.exe -m pytest -q tests/test_i18n.py`는 영어 누락/자리표시자/설정 저장 실패/다섯 언어의 새 프로세스 실제 분석을 검사한다.

`--self-test-language <언어 코드> <새 JSON 경로>`는 개인 파일 대신 출력 위치 아래 직접 만든 시험 자료로 오프스크린 시작 검사를 수행한다. `QT_QPA_PLATFORM=offscreen`을 지정해 사용한다. 기본 명령은 `scripts/run.pyw`, 배포판은 `DevStorageManager.exe`이다. 실제 휴지통 이동이나 환경 자격 승인은 하지 않는다.

## 확인 범위

다섯 언어의 소스 프로세스에서 표제·버튼 번역, 한국어/베트남어/일본어/중국어 경로의 분석·검토·기록, 정리 비활성을 확인했다. 배포 스크립트도 독립 EXE의 다섯 언어 자체 검사를 통과해야 패키지를 만들도록 한다. 결과는 배포 폴더 `LANGUAGE-CHECKS.json`에 보관한다. 실제 물리 화면의 모든 DPI·폰트·OS 언어 조합과 전문 번역 품질은 검증하지 않았다.
