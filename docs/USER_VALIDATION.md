# 사용자 환경 검증 기록

## 2026-10-31 · 0.6.1 수정판 안내 후 사용자 보고

사용자가 앱의 환경 점검 결과를 직접 제공했다. 아래는 사용자가 실행한 시험의 보고이며 에이전트가 해당 PC를 독립적으로 조작하여 재현한 결과는 아니다.

| 항목 | 제공된 결과 |
|---|---|
| 링크 경계 | 통과. 바깥 경로 탐색 및 링크 루트 등록 차단 |
| 읽기 전용·보호 경로 | 통과. .git/앱 데이터 시험 경로 제외 및 원본·캐시 집계 |
| 휴지통 연동 | 통과. 시험 캐시 영수증 및 원래 경로 소멸 확인 |
| 작업 후 원본 보존 | 통과. 시험 소스/.git/보호 자료/바깥 자료 보존 |

이는 앱이 생성한 시험 자료에서 실제 휴지통 연동이 사용자 환경의 모든 점검을 통과했다는 근거다. 현재 실행 세션에서 Python 3.12 캐시 후보의 개별 내용/변경 검증과 명시적 동의를 진행할 수 있다. 이전의 0x00270008 오판 수정 후 성공 결과가 제공되었다.

### 아직 확인하지 않은 범위

- 사용자가 등록한 실제 프로젝트 후보의 검토부터 정리 이력까지 전체 흐름.
- Windows 휴지통에서 시험 캐시를 직접 복원하여 내용과 위치를 확인하는 수동 복원 시험.
- 재시작 후 실행 승인 초기화의 실제 사용자 환경 시험(단위/UI 검사 근거와 구분).
- 별도 깨끗한 Windows 설치, Windows 10, 모든 DPI 배율, 추가 정리 유형.

정식 완료를 선언하거나 미지원 유형을 활성화하지 않는다. 자동 복원/휴지통 비우기/영구 삭제 전환을 추가하지 않는다. GitHub 업로드 보류를 유지한다.
