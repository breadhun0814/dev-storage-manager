- 폴더가 매우 많으면 결과 표 생성 시 UI 지연 가능. 취소는 OS 호출이 돌아온 뒤 반영된다.
- 전체 UI/오류의 번역 카탈로그 분리는 미완료(공통 상태·문구만 분리).
- 개발 유형 분류, 후보 판별/포함 파일 검토, 사용자 제외 목록, 정리 계획·변경 검증·휴지통·정리 이력·재분석 비교·보고서 모두 후속 단계.
- 정리/실패 fallback/휴지통 복원 관련 시험은 실행 기능이 없어 아직 수행하지 않음.
