# 필수 검증과 완료 기준 대조

이 문서는 시험 개수와 제품 완성 여부를 구분한다. 실제 개인 프로젝트는 시험에 사용하지 않는다. 테스트 이름과 코드는 tests/에서 확인할 수 있다.

0.16.0 전체 검사는 **197 passed, 3 skipped**이다. 영어 대체/자리표시자/설정 유지 및 저장 실패/다섯 언어의 새 Qt 프로세스 실제 분석을 검사했다. VALIDATION_0160.md와 LOCALIZATION.md 참고. 완역·전문 검수·실제 휴지통 복원 검증을 의미하지 않는다.

0.15.0 최신 전체 검사는 **182 passed, 3 skipped**이다. 검토 중간 목록의 누락/중복을 주입해 수정 전 실패를 재현하고 수정 후 차단했다(VALIDATION_0150.md). 최초 계획 전체와 미완료 배포 조건은 RELEASE_AUDIT.md에 대조한다. 링크 생성 3건의 skip과 사용자 환경 보고를 통과로 합산하지 않는다.

| 사용자 필수 검증 | 현재 근거 | 판정 |
|---|---|---|
| 분석 후 원본 내용 불변 | test_scanner: 임시 파일 바이트/수정 시각 대조 | 해당 임시 입력 통과 |

추가: 330자 이상 경로 분석·캐시 검토, 저장 트랜잭션 실패, 보고서/비교 중 화면 응답, 숫자 정렬과 문자 그대로 검색, 초기 정리 미선택/비활성 시험을 수행했다.

실제 하드링크 집계/정리 거부 시험은 작성했으나 이 실행 환경이 생성 자체를 거부하여 건너뛰었다. 실제 심볼릭 링크/junction과 합쳐 최신 건너뜀은 3개다. 이를 성공 근거로 사용하지 않는다.

## 첫 배포 완료 기준

| 기준 | 현재 상태 |
|---|---|
| 등록 → 분석 → 검토 | 임시 파일 통합 시험 및 시험 EXE 시작 검사 통과 |
| 검토 → 실제 휴지통 이동 | 코드 연결/실행 전 검증/환경 시험 제한 구현. 0.6.1 Python 시험 캐시 이동은 사용자 보고로 확인. 최신 pytest 유형/전체 UI 실제 이동은 미검증 |
| 후보 근거와 미지원 설명 | UI와 SUPPORT.md에 구현 |
| 실패를 성공으로 표시하지 않음 | 실패/미확정 대역과 실제 차단 시험 통과. 일반 환경 긍정/복원 검증 필요 |
| 원본 보호 시험 | 실제 임시 DACL 제한/복구와 공유 잠금은 통과. 에이전트의 링크 3종 생성은 거부됨. 사용자 보고의 경계 시험 통과와 구분하고 전체 완료로 판정하지 않음 |
| Windows 실행 배포물 | 로컬 portable 시험 EXE 있음. 별도 깨끗한 Windows 환경 검증/서명 미완료 |
| 설치·실행·테스트·한계 문서 | README, QUICKSTART, SUPPORT, DEPLOYMENT, PROGRESS 제공 |

따라서 **정식 첫 배포 완료는 아직 입증되지 않았다**. 최신 유형의 실제 이동·수동 복원과 깨끗한 Windows 배포의 증거를 확보한 뒤 다시 판정한다. Windows 10은 시험 전까지 지원으로 표시하지 않는다.
