# 0.6.2 빈 후보 결과 확인

사용자가 후보 표 전체가 비어 있다고 보고했다. 사용자 프로젝트의 내용을 추정하거나 새 후보를 만들어 채우지 않았다.

- 전체 pytest: **92 passed, 3 skipped** (`work/pytest-062-release`).
- 직접 생성한 README 파일만 있는 시험 폴더를 실제 스캔하고, 완료된 결과의 후보가 없을 때 안내·용량 보기·선택/검토 비노출을 확인했다.
- 용량 보기 버튼이 실제 폴더 결과 탭으로 연결되고, 미분석 프로젝트로 전환하면 이전 안내/결과가 남지 않는지 확인했다.
- 취소/불완전/실패 결과를 후보 부재의 확정으로 표시하지 않고, 제외 범위가 있는 결과는 읽은 범위만 설명한다.
- 생성한 임시 자료를 사용한 1040×760 offscreen Qt 화면을 확인했다. outputs/ui-0.6.2-no-candidates.png. 실제 사용자 프로젝트나 모든 모니터/DPI 시험을 의미하지 않는다.
- 정리 유형과 권한/내용 검증을 확대하지 않았다. 사용자 환경 0.6.1의 환경 점검 통과 근거는 USER_VALIDATION.md에 별도 보존한다. 실제 프로젝트 전체 정리 흐름과 수동 복원은 별도 확인이 필요하다.
- 코드·문서·로컬 배포물만 갱신하며 GitHub 업로드는 보류한다.
