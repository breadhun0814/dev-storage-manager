## 수행한 검사

환경: Windows Python 3.12.14 x64, PySide6 6.10.2, pytest 9.0.2. 의존성 설치 성공, pip check 성공. 호스트 Windows 제품명/버전은 CIM 접근 거부로 확인하지 못했으므로 Windows 11 전체 호환을 검증했다고 표시하지 않는다.

최종 명령: `.venv\Scripts\python.exe -m pytest -q --basetemp work\pytest-final` → **10 passed, 2 skipped**.

통과: 한국어/공백 경로, 원본 바이트와 수정 시각 불변, 중첩 집계, .git 제외/직접 진입 거부, 보호 경로, 읽기 거부 주입 시 불완전 표시, 시작 전/도중 취소, reparse 플래그 판별, SQLite 재시작 중단 상태, 목록 제거 원본 보존, 실제 Qt 작업 스레드 결과 연결, 느린 작업 대역에서 이벤트 루프 취소 전달.

건너뜀: 실제 심볼릭 링크·junction 생성. 실행 환경에서 권한이 거부되어 경계 밖 탐색 실증은 미완료. 플래그 단위 시험으로 이를 대체 검증했다고 주장하지 않는다.

Qt offscreen으로 임시 시험 프로젝트의 창을 렌더링하고 이미지 확인. 한글 기본 폰트가 사각형으로 나오는 문제를 발견하여 Windows 맑은 고딕 로딩을 추가하고 재확인. 이는 실제 모니터에서 파일 선택 대화상자와 모든 조작을 수동 검증한 것은 아니다.

## 남은 문제와 미완료

- 실제 Windows 11 일반 사용자/깨끗한 환경 시험, Windows 10 시험, exe 배포·서명·설치 미완료.
- 이 런타임의 기본 TEMP 접근 오류가 있어 의존성 설치 때 프로젝트 work/tmp를 사용했다. 가상환경 초기 ensurepip도 실패하여 번들 pip로 프로젝트 가상환경에 pip를 설치했다.
- 편집 설치는 긴 임시 경로에서 WinError 3으로 실패. scripts/run.pyw는 편집 설치 없이 동작하며 Qt 생성/분석/결과는 시험했다. pythonw 프로세스의 실제 사용자 화면 실행은 미확인.
- 실제 권한 거부 폴더는 미시험(주입 시험만 수행). 사용 중 파일, 긴 경로, 대규모/네트워크 폴더 성능 실측 미완료.
- 외부 동시 변경에 대한 원자적 경계 보장 없음. 읽기 결과는 스냅샷이 아니며 정리용 근거로 사용할 수 없음.
- 폴더가 매우 많으면 결과 표 생성 시 UI 지연 가능. 취소는 OS 호출이 돌아온 뒤 반영된다.
- 전체 UI/오류의 번역 카탈로그 분리는 미완료(공통 상태·문구만 분리).
- 개발 유형 분류, 후보 판별/포함 파일 검토, 사용자 제외 목록, 정리 계획·변경 검증·휴지통·정리 이력·재분석 비교·보고서 모두 후속 단계.
- 정리/실패 fallback/휴지통 복원 관련 시험은 실행 기능이 없어 아직 수행하지 않음.
