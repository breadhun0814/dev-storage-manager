# 0.15.0 검토 목록 일치성 검사 · 2026-10-31

## 재현한 문제

기존 검토는 후보를 분석하고 포함 목록을 읽은 뒤 다시 분석하여 앞뒤 지문을 비교했다. 두 분석이 같더라도 중간 포함 목록에 누락/중복이 있으면 잘못된 내용 검토가 통과할 수 있었다.

개인 파일 대신 임시 Python 프로젝트의 실제 pyc와 같은 크기의 `personal.txt` 시험 파일을 만들었다. `test_review_consistency.py`는 두 번째 scandir 열거에만 다음 결함을 주입한다. 처음/마지막 분석은 모두 정상 목록을 읽는다.

- 알 수 없는 파일을 중간 포함 목록에서 누락.
- 그 파일을 누락하고 같은 크기의 알려진 pyc를 중복 반환. 개수/크기만 비교하면 탐지할 수 없는 경우.

수정 전 두 경우 모두 검토가 예외 없이 통과하여 **2 failed**를 재현했다. 실제 정리/휴지통 요청은 하지 않았다.

## 변경과 검사

`cleanup/review.py`는 포함 목록을 읽을 때 직접 관측한 디렉터리 식별 정보/엔트리 메타데이터를 기존 scanner와 같은 지문 함수로 결합한다. 하위 폴더까지 구성한 지문, 파일 수, 논리적 크기, 고유 경로 수를 분석 결과와 대조한다. 목록이 다르면 재분석을 요청하며 실행 계획을 만들지 않는다. 기존 마지막 재분석·내용 검사·OS 직전 검증도 유지한다.

- 수정 후 회귀/서비스/UI/pytest 캐시 관련 검사: **34 passed** (`work/pytest-audit-0150-after`).
- 전체 검사: **182 passed, 3 skipped**, 20.86초 (`work/pytest-0150-final`).
- 세 skip은 실제 링크 생성 제한이며 통과로 표시하지 않는다.
- 임시 원본과 누락 시험 파일/pyc 보존을 확인했다. 검사 과정에서 개인 파일 또는 실제 휴지통을 사용하지 않았다.
- 소스 offscreen 자체 검사: 버전 0.15.0, 실제 임시 분석/검토/시험 프로젝트/SQLite 이력/미확인 용량/비동기 폴더 검색 확인, 정리 자격 없음·정리 비활성 (`work/startup-0150-source.json`).
- Windows GUI 빌드는 완료했다. 독립 EXE 자체 검사는 배포 폴더의 STARTUP-CHECK.json, 파일 무결성은 SHA256.json 및 `scripts/verify_package.py`로 확인한다.

이 시험은 열거 결함을 주입한 논리 회귀 검사다. Windows OS 자체가 같은 형태로 목록을 누락한 현상을 실증하거나 모든 외부 경합을 원자적으로 막았다는 뜻은 아니다. 실제 휴지통 이동/수동 복원/깨끗한 설치는 RELEASE_AUDIT.md의 남은 항목이다. 지원 정리 유형과 환경 자격 조건을 확대하거나 우회하지 않았다.
