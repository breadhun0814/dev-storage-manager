# 개발 진행 현황 — 2026-10-31

현재 로컬 버전: **0.8.0 개발 묶음**. 정식 배포 완료가 아니다. 이전 개발 기록은 HISTORY.md에 보존한다.

0.8.0 진행: 폴더별 용량에서 선택한 폴더의 현재 직접 항목을 읽는 탐색 창을 추가했다. 분석에 포함된 등록 경계 안에서만 이동하며 현재 제외 목록/.git/앱 보호/링크 제한을 적용한다. 파일 행은 경로·논리적 크기 확인용이고 실행/삭제하지 않는다. 폴더 크기는 알 수 없는 0 B로 표시하지 않는다. 분석 후 새 하위 폴더는 재분석 전 열지 않는다. 최대 5,000개 표시/불완전/취소를 구분한다. 읽기는 작업 스레드이며 취소 또는 닫기 후 창이 다시 열리지 않는다. 기존 분석/정리 정책을 변경하지 않았다.

Python 캐시 증거를 대응 원본 내용의 해시에도 결합했다. pyc의 초 단위 수정 시각/크기가 같아도 검토 이후 원본 내용이 바뀌면 실행을 차단한다. 직접 만든 임시 자료와 실제 원본 DACL 제한으로 폴더 읽기 실패를 검사하고 원래 DACL을 복원했다. 전체 검사를 다시 수행하고 배포 시작 검사까지 마친 뒤 묶음 상태를 기록한다. 사용자 중간 확인과 GitHub 업로드는 요청하지 않는다.

0.8.0 전체 검사 **129 passed, 3 skipped** (`work/pytest-080-combined`), 소스 자체 시작/실제 분석/큰 파일 2행/폴더 내용 2행/초기 정리 비활성 확인. 일반 창과 작은 창의 실제 임시 폴더 탐색 화면을 확인했다. 자세한 범위는 VALIDATION_080.md에 기록한다. 정식 완료나 별도 정상 Windows의 휴지통 복원 검증으로 표현하지 않는다.

## 미완료·미검증

1. 현재 환경에서 실제 junction 생성이 거부되어 해당 시험 2개는 건너뛰었다. 판별/핸들/대역 검사를 실제 링크 시험 성공으로 대체하지 않는다.
2. 실제 임시 캐시 휴지통 요청은 필수 플래그가 없어 차단됐다. 일반 Windows 환경의 이동 성공과 수동 복원 검증이 필요하며 사용자에게 환경 시험 결과를 요청했다.
3. 깨끗한 별도 Windows 11의 전체 흐름/배포/서명, 긴 경로의 실제 휴지통 이동 검증이 남아 있다. Windows 10 지원은 미확인이다.
4. pytest 캐시·가상환경·node_modules·빌드 결과의 실제 정리는 미지원이다. 검증을 마친 유형만 활성화한다.
5. 백만 파일, 네트워크, 다수 오류, DPI, 외부 동시 변경의 추가 시험이 필요하다. 모든 경합을 원자적으로 배제하지 않는다.
